# BlindCalc

### AI-Powered Voice Scientific Calculator for Accessible Mathematics

BlindCalc is an accessibility-focused scientific calculator that allows
users to perform mathematical calculations using natural voice input.

The application combines speech recognition, AI-powered transcription,
mathematical expression processing, and text-to-speech feedback to provide
a hands-free calculation experience.
## Problem

Traditional scientific calculators rely heavily on visual interfaces,
making mathematical computation difficult for users with visual
impairments.

BlindCalc addresses this accessibility gap by allowing users to interact
with a scientific calculator primarily through voice.
## Key Features

- 🎙️ Voice-based mathematical input
- 🤖 AI-powered speech transcription
- 🧮 Scientific mathematical expression evaluation
- 🔊 Text-to-speech calculation feedback
- ♿ Accessibility-focused interaction
- ⚡ React-based responsive interface
- 🔗 REST API communication with the backend
- ☁️ Cloud deployment
- ## How It Works

User Voice Input
        ↓
Speech Recognition
        ↓
AI Transcription
        ↓
Mathematical Expression Processing
        ↓
SymPy Calculation Engine
        ↓
Result
        ↓
Text-to-Speech Feedback
1. The user speaks a mathematical expression.
2. The audio is processed and converted into text.
3. The backend processes the transcribed mathematical expression.
4. The expression is evaluated using the mathematical engine.
5. The result is returned to the frontend.
6. The result is communicated back to the user through speech.
